# Lite Memo

터미널에서 간단하게 열람/편집!

---

## 빌드 & 실행

```bash
gcc main.c -o litememo
./litememo
```

실행 후 편집할 텍스트 파일명을 입력합니다.

```
Type name of text file >>> memo.txt
```

> 파일이 존재하지 않으면 오류가 발생합니다. 미리 파일을 생성해 두세요.

---

## 명령어

파일 내용이 출력된 뒤 `>>>` 프롬프트에서 아래 명령어를 입력합니다.

| 명령어 | 설명 | 예시 |
|---|---|---|
| `end]` | 프로그램 종료 | `end]` |
| *(텍스트 입력)* | 파일 맨 끝에 새 줄 추가 | `오늘 할 일` |
| `N]텍스트` | N번째 줄을 텍스트로 **덮어쓰기** | `3]수정된 내용` |
| `N]+텍스트` | N번째 줄 끝에 텍스트 **이어붙이기** | `2]+추가 내용` |
| `del]N` | N번째 줄 **삭제** | `del]4` |
| `del]N-M` | N번째부터 M번째 줄까지 **범위 삭제** | `del]2-5` |
| `del]N-` | N번째 줄부터 **마지막 줄까지 삭제** | `del]3-` |

---

## 동작 방식

- 매 명령 실행 후 화면을 초기화하고 파일 전체 내용을 다시 출력합니다.
- 줄 번호는 화면 왼쪽에 `  N]` 형식으로 표시됩니다.
- 삭제·수정 시 내부적으로 `temp.txt`를 임시 파일로 사용하며, 작업 완료 후 원본 파일로 교체됩니다.

---

## 주의사항

- 같은 디렉터리에 `temp.txt`가 있으면 덮어써집니다.
- 한 줄 최대 길이는 **255자**입니다.
- Windows / Linux / macOS 환경에서 모두 빌드 가능합니다.
